## 🌐 Deploying to Vercel

1. Import the repository `Jatinprajapati7869/JatinPr` on [Vercel](https://vercel.com/new).
2. Leave Framework Preset as **Other** (Root Directory `./`, zero build commands needed).
3. Click **Deploy**. Vercel will deploy the site globally to its edge CDN.
4. Go to **Project Settings → Domains** to connect your custom domain:
   - Apex domain (`yourdomain.com`): Add an **A Record** pointing to `76.76.21.21`
   - Subdomain (`www.yourdomain.com`): Add a **CNAME Record** pointing to `cname.vercel-dns.com`
